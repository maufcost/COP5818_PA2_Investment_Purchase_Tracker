1. How does an HTML ID connect a form control to JavaScript?

An HTML ID gives a form control a unique name. JS uses the function "document.getElementbyId()" with that ID to access and handle that form.

2. Why convert quantity and unit price with Number?

Mainly because input values are returned as strings even when use number inputs. By using Number(), we manage to convert those strings to numerical values (e.g. quantity and price) correctly, so we can do math later like multiplication and addition.

3. Why clear the old history before rebuilding it?

So that we don't display entries multiple times. If we did not clear it, we would have the previous list elements displayed, thus showing duplicates.
