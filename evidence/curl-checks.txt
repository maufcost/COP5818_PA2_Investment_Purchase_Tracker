# curl evidence (2026-11-07 21:03, curl 8.7.1)
# Users are fictional. Session cookies are kept in temporary cookie jars; CSRF tokens and cookie values are never printed.
# Format: $ METHOD path [body]  ->  HTTP status and JSON response

## Check 1 - registration and login
$ POST /api/register {"email":"  CURL.A@Example.TEST ",...}
  -> 201 {"id":4,"email":"curl.a@example.test"}
$ POST /api/register {"email":"curl.b@example.test",...}
  -> 201 {"id":5,"email":"curl.b@example.test"}
$ GET /api/me   (right after registering A: not logged in)
  -> 401 {"error":"Login required"}
$ POST /api/register   (duplicate email curl.a@example.test)
  -> 409 {"error":"An account with that email already exists"}
$ POST /api/register   (password "short")
  -> 400 {"error":"Password must be 8-128 characters"}
$ POST /api/register   (129-character password)
  -> 400 {"error":"Password must be 8-128 characters"}
$ POST /api/register   (email "not-an-email")
  -> 400 {"error":"Enter a valid email address such as user@example.com"}
$ POST /api/login   (A, wrong password)
  -> 401 {"error":"Invalid email or password"}
$ POST /api/login   (unknown email)
  -> 401 {"error":"Invalid email or password"}
$ POST /api/login   (A, correct password)
  -> 200 {"id":4,"email":"curl.a@example.test"}
$ GET /api/me   (A)
  -> 200 {"id":4,"email":"curl.a@example.test"}

## Check 2 - logged-out access and CSRF
$ GET /api/purchases   (no session)
  -> 401 {"error":"Login required"}
$ GET /api/categories   (no session)
  -> 401 {"error":"Login required"}
$ POST /api/purchases   (valid CSRF token, not logged in)
  -> 401 {"error":"Login required"}
$ DELETE /api/purchases/1   (valid CSRF token, not logged in)
  -> 401 {"error":"Login required"}
A before: {"count":0,"totalCents":0,"records":[]}
$ POST /api/purchases   (A logged in, NO X-CSRF-Token header)
  -> 403 {"error":"CSRF token rejected"}
$ POST /api/purchases   (A logged in, WRONG token)
  -> 403 {"error":"CSRF token rejected"}
$ POST /api/purchases   (A logged in, Origin: http://evil.example)
  -> 403 {"error":"Origin rejected"}
$ POST /api/login   (no X-CSRF-Token header)
  -> 403 {"error":"CSRF token rejected"}
A after:  {"count":0,"totalCents":0,"records":[]}
